📝 ToDo List API — Mini Project

API REST simples para gerenciamento de tarefas (ToDo List), desenvolvida com Java + Spring Boot.
O projeto permite criar, listar, atualizar e remover tarefas associadas a usuários.

Este projeto foi desenvolvido como prática de backend utilizando conceitos de:

-Spring Boot

-API REST

-Persistência de dados

-Arquitetura MVC

-Boas práticas com Java

🚀 Tecnologias utilizadas

-Java 17+

-Spring Boot

-Maven

-Spring Web

-Spring Data JPA

-Banco de dados H2

-Hibernate

⚙️ Funcionalidades

✅ Criar tarefas

📋 Listar tarefas

✏️ Atualizar tarefas

❌ Remover tarefas

👤 Associação de tarefas com usuário

⏱️ Validação de datas (início e fim)
